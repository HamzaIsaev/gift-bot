## Что это
Бот для торговли NFT-подарками Telegram на Portals, Tonnel и MRKT. Подробности в `README.md`.
- **Режимы:** наблюдение (виртуальные сделки, по умолчанию) и боевой. Боевой включается только явным подтверждением.
- **Обязательные лимиты:** `max_trade`, `max_daily_loss`, `max_positions`, `/stop`.
- **Управление:**
  - Telegram-бот (aiogram 3);
  - админ-панель / Mini App (aiohttp, `gift_bot/panel/index.html`, стиль TON/Notcoin);
  - кнопка меню «APP»;
  - синхронизация через SSE `/api/events`.
- **Торговая математика v2** (`engine/decision_v2.py`, `pricing/analytics.py`):
  - работает только в наблюдении (`STRATEGY_V2_LIVE=false`);
  - бэктест: `scripts/backtest.py`.
- **Настройки** редактируются в панели: `settings_registry.py` (28 пунктов, пресеты), значения хранятся в БД.

## Вход на площадки (api_id из России получить не удалось)
- `TG_API_ID` пуст, поэтому initData забирается через Playwright из Telegram Web K: `gift_bot/markets/web_login.py`.
- Способы входа:
  - `/login`: по номеру через бота; код вводится **с пробелами**, бот удаляет сообщения;
  - `/qr`: по QR-коду;
  - `/auth <market> <initData>`: вручную.
- Профиль браузера: `data/tg_web_profile`. Данные обновляются в фоне каждые 6 часов.
- Вёрстка Telegram Web меняется. Новая версия не даёт страницам классов `page-*`, поля имеют CSS-модульные классы (`_input_xxx`).
  - Поэтому поля ищутся по всей странице (`FIELD_SELECTORS`).
  - Шаг после номера определяется в `_where_after_phone`.
  - Признаки входа собраны в `LOGGED_IN_JS`.
- При ошибке бот присылает снимок экрана и `debug_info` (адрес, страницы, кнопки, поля, ключи хранилища). По ним правятся селекторы.

## Разработка
- Ветка `claude/confident-euler-wub4ot`, репозиторий `HamzaIsaev/gift-bot` (приватный).
- После push выполнить `git fetch origin "+refs/heads/claude/confident-euler-wub4ot:refs/remotes/origin/claude/confident-euler-wub4ot"`, иначе stop-hook ругается.
- Тесты: `.venv/bin/python -m pytest -q` (около 82 шт., примерно 2 минуты; браузерные тесты используют `/opt/pw-browsers`).
- Из облачного контейнера недоступны Telegram и площадки, поэтому реальная сеть не проверяется. Проверка идёт на имитациях в тестах.
- Безопасность:
  - секреты только в `.env`; токены, сессии и initData не коммитить;
  - не просить пользователя присылать пароли или токены в чат;
  - не советовать сторонние «боты для api_id».
- Торговые запросы выполняются через `once()` без повторов, чтобы не было двойной покупки.
- Комиссии площадок в `.env` — это допущения: пользователь должен сверить их перед боевым режимом.
- В коммитах не указывать модель.
