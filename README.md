# Gift Bot

Бот для торговли NFT-подарками Telegram на Portals, Tonnel и MRKT.
Он ищет лоты дешевле рынка, перепродаёт их и отдельно сигналит о межплощадочном арбитраже.

**Текущая версия работает только в режиме наблюдения.** Бот ничего не покупает,
а записывает виртуальные сделки и считает, какую прибыль они бы дали. Боевой режим будет добавлен после подтверждения.

## Как работает

1. Каждые `POLL_INTERVAL_SEC` секунд бот забирает с каждой площадки новые лоты и последние продажи.
2. Рыночная цена модели считается как среднее floor (самого дешёвого другого лота) и медианы продаж за `SALES_WINDOW_DAYS` дней.
   Если продаж мало, берётся только floor.
3. Расчёт сделки: затраты = цена × (1 + комиссия покупателя) + сетевой сбор.
   Выставление идёт чуть ниже рынка, но не выше floor.
   На руки = цена выставления × (1 − комиссия продавца) − сетевой сбор.
4. Сигнал на покупку появляется, если прибыль ≥ порога (`MIN_PROFIT_PCT`, по умолчанию 12%).
5. **Адаптивность** (`ADAPTIVE=true`):
   - для неликвидных моделей порог выше (+8%), для ликвидных ниже (−2%);
   - для волатильных моделей порог выше;
   - модели, на которых недавно был убыток, пропускаются на `LOSER_COOLDOWN_DAYS` дней;
   - если сегодня уже потеряно больше половины дневного лимита, порог выше (+3%);
   - если рынок ушёл ниже нашей цены, цена сразу подтягивается под floor.
6. Если подарок не продаётся `REPRICE_AFTER_HOURS` часов, цена снижается на `REPRICE_STEP_PCT`%,
   но **никогда не ниже безубыточности** (цена покупки + комиссии).
7. Арбитраж: тот же подарок дешевле на одной площадке и дороже на другой.
   С учётом `TRANSFER_COST_TON` это только сигнал, без автосделки.
8. Виртуальная продажа засчитывается, когда на площадке проходит продажа той же модели не дешевле нашей цены.

## Лимиты (обязательные)

- `max_trade`: максимальная сумма одной сделки.
- `max_daily_loss`: максимальный дневной убыток. При достижении бот прекращает покупки до конца дня и пишет вам.
- `max_positions`: максимум подарков на балансе одновременно.
- `/stop`: мгновенно останавливает всё, включая переоценку. Состояние сохраняется после перезапуска.

## Команды Telegram-бота

Меню содержит кнопки «Статус», «Режим», «Лимиты», «Стоп».

| Команда | Что делает |
|---|---|
| `/status` | баланс, открытые позиции, прибыль за день и за всё время |
| `/mode` | переключение режима и снятие `/stop` |
| `/limits` | просмотр лимитов; изменение: `/limits max_trade 25` |
| `/report` | отчёт за неделю |
| `/stop` | аварийная остановка |

Еженедельный отчёт приходит по понедельникам в 9:00 (`REPORT_WEEKDAY`, `REPORT_HOUR`).

## Установка

### Что понадобится
- **Сервер:** VPS с 1 vCPU и 1 GB RAM, Ubuntu 22.04/24.04, Docker. Лучше в Европе (Нидерланды или Германия).
- **Управляющий бот:** создайте у [@BotFather](https://t.me/BotFather) и получите `BOT_TOKEN`.
- **Отдельный Telegram-аккаунт** для входа на площадки:
  - получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org) в разделе API development tools;
  - откройте с этого аккаунта Portals, Tonnel и MRKT хотя бы один раз (чтобы принять условия).

### Быстрый старт на Mac
1. Скачайте код (Code → Download ZIP) и распакуйте.
2. Откройте файл `Запустить.command`. Если macOS не даёт его открыть, нажмите правой кнопкой → «Открыть».
3. Ответьте на вопросы. При первом запуске скрипт сам установит зависимости, создаст `.env` и выполнит вход в Telegram, а затем запустит бота.

### Шаги (сервер)
```bash
git clone https://github.com/HamzaIsaev/gift-bot.git && cd gift-bot
cp .env.example .env            # заполнить BOT_TOKEN, ADMIN_IDS, TG_API_ID, TG_API_HASH

# одноразовый вход в Telegram-аккаунт -> TG_SESSION_STRING
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
python scripts/login.py         # вставить выданную строку в .env

docker compose up -d --build    # запуск 24/7 с автоперезапуском
docker compose logs -f          # логи
```

## Безопасность

- Все ключи и сессия хранятся только в `.env`, а `.env` добавлен в `.gitignore`.
- Логи автоматически вычищают токены, сессию и initData.
- `TG_SESSION_STRING` даёт полный доступ к Telegram-аккаунту. Никому её не передавайте.
- Сид-фраза кошелька в режиме наблюдения не нужна.

## Данные для анализа

Всё пишется в SQLite (`data/gift_bot.sqlite3`):
- `sales`: продажи на площадках;
- `signals`: каждый интересный лот с расчётом и решением (`buy`, `skip` с причиной, `signal` для арбитража);
- `positions`: виртуальные и реальные сделки с прибылью;
- `settings`: режим, лимиты и `/stop`.

## Важно

- API площадок **неофициальные**. Они могут измениться, а автоматизация может нарушать правила площадок.
- **Комиссии в `.env` нужно сверить** с мини-приложениями перед боевым режимом.
