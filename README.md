# gift-bot

Лендинг Telegram-бота для обмена подарками (гарант-сделки, маркет, оценка стоимости).

Статический сайт: `index.html`, `styles.css`, `app.js` — без сборки.

- Ссылка на бота задаётся в `app.js` → `BOT_URL`.
- Демо-подарки для маркета и калькулятора обмена — массивы `GIFTS` и `LOTS` в `app.js`.
- Локальный запуск: `python3 -m http.server`.
